# SHADOW RIFT // Trainer Deck: Lucas

Static birthday coupon deck served at https://lucas.arylandco.com via GitHub Pages.

## What the page does
- Cards 001-004: $20, live 07.08.2026 (countdown flips automatically, America/Chicago)
- Cards 005-008: $20, encrypted. Live countdown in the band; at 12:00 AM CT on 07.15.2026
  the seals, veils, and datamosh bars dissolve on their own and the status pills flip to Live.
- Card 000: The Alpha & Omega. No dates. Always valid.
- Page stays fully printable (Print button, Letter, Background graphics ON).

## Deploy (already done if you are reading this on GitHub)
1. Repo > upload these 4 files to the root of main.
2. Settings > Pages > Deploy from a branch > main / (root).
3. Custom domain auto-fills from the CNAME file: lucas.arylandco.com. Check "Enforce HTTPS" once available.
4. DNS at the arylandco.com provider: CNAME record, host "lucas", value "nickary83.github.io".

Backup URL before DNS propagates: https://nickary83.github.io/<repo-name>/
